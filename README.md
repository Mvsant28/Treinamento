# 🚗 Madri Motors | Concessionária de Carros de Luxo

Aplicação web moderna (Single Page Application) desenvolvida para a apresentação e agendamento de propostas de veículos exclusivos de alto luxo.

## 🛠️ Tecnologias Utilizadas
* **HTML5 Semântico** (em conformidade com as diretrizes WCAG 2.1)
* **CSS3** (Flexbox, Grid Layout e Design Responsivo)
* **JavaScript Moderno (ES6+ Modules)**
* **Git e GitHub** para controlo de versão

## 📌 Funcionalidades
* Galeria dinâmica renderizada via JavaScript com dados estruturados (`carros.js`).
* Efeitos visuais em CSS com cartões interativos.
* Formulário de agendamento validado e integrado com `localStorage`.
